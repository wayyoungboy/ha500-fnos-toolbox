# HA500 飞牛工具箱需求基线

## 目标

在一个 fnOS 原生应用中提供奥睿科 HA500 的硬盘灯、风扇控制和诊断能力。应用以单个 Go 服务运行，不依赖 Python、CoolerControl 或常驻浏览器。

首版只支持已经验证的 HA500 硬件组合，不承诺兼容其他机型，也不打包第三方内核模块。

## 硬件边界

- 硬盘灯：识别 ASM1166 SATA 控制器下的端口，默认将前五个端口映射到五个盘位；允许用户在 1～6 号控制器端口中手动重排五个盘位。
- 灯光：GPIO 为低电平点亮，只控制五个蓝色盘位灯，不控制故障灯、电源灯或状态灯。
- 风扇：识别 `it87` 暴露的 hwmon 通道。只有同时存在可写 PWM 和有效转速反馈的通道，才能申请控制权。
- 温度：支持 `coretemp` 的 CPU Package 和按序列号 SHA-256 指纹识别的 SATA 硬盘 SMART 温度；不存在可靠温度源时禁止保存控制策略，运行中温度源丢失时进入全速保护。
- 驱动：当前内核无法提供 `it87`/PWM 接口时进入只读诊断状态，不尝试写入未知硬件。

## 控制模型

### 硬盘灯

- 自动模式：盘位对应端口检测到硬盘时蓝灯亮，空盘位灯灭。
- 手动模式：五个灯可独立开关，仅用于核对物理盘位；服务重启后恢复自动模式。
- 端口映射保存到应用私有配置，写入必须原子化且权限为 `0600`。

### 风扇

每个风扇通道独立保存以下设置：

- 仅监控：只显示 PWM、RPM 和温度，不写硬件。
- 自动曲线：按该通道自己的温度源和曲线计算 PWM。
- 固定转速：保持该通道的固定 PWM 占空比。
- 全速保护：始终保持 100%。

每路策略都包含最低占空比、临界温度和转速校验。通道之间不共享曲线或固定值。

## 安全约束

- 默认仅监控；完成软件控制验证且不存在其他风扇控制服务时，用户才能启用写控制。
- 验证只对单路风扇短时增加约 10%～15% 占空比并自动恢复；当前已为 100% 时，不经明确确认不得主动降速。
- PWM 回读成功但 RPM 无明显变化时，标记为“接口存在，物理效果未验证”，提示检查 BIOS/EC 或 PWM/DC 模式。
- 温度读取失败、受控风扇 RPM 异常、服务正常退出或崩溃恢复时，应用拥有的风扇必须切换到手动 100%。
- 监控模式、硬件不匹配、驱动缺失、权限不足或发现 CoolerControl/fancontrol 等冲突服务时，不写 PWM。
- 不控制没有转速反馈的 PWM 通道，不根据通道编号猜测物理风扇。

## 原生界面与 API

应用包含四个页面：概览、硬盘灯、风扇控制、运行日志。所有变更接口仅允许 fnOS 管理员通过应用 Unix Socket 网关访问。

- 概览：五盘位、每路风扇、CPU 温度、驱动和硬件匹配状态。
- 硬盘灯：自动/手动模式、五灯开关、控制器端口映射和即时诊断。
- 风扇控制：通道列表、单通道独立策略、控制验证与冲突检测。
- 运行日志：有界日志展示、下载、刷新和一键清空。

诊断结果不得包含明文磁盘序列号、用户名、密码、私有路径、IP 地址或令牌；只允许返回用于稳定识别的序列号 SHA-256 指纹和派生短 ID。

## 生命周期

- 安装后默认只读，不自动接管风扇。
- 停止、升级、卸载前先把本应用拥有的风扇置为 100%，再终止服务。
- 日志按大小轮转，配置和日志位于 fnOS 分配的包变量目录。
- 测试安装工具箱前，先卸载旧的 HA500 硬盘灯应用并确认其进程、Socket 与安装路径均已消失。
